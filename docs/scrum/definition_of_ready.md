# Definition of Ready

A story can enter a sprint only when all of these are true:

- [ ] Written as "As a <role>, I want <capability>, so that <value>"
- [ ] Linked to at least one Req ID (FR/NFR) in docs/requirements.md and the RTM
- [ ] Acceptance criteria are testable Given/When/Then with measurable results
- [ ] Estimated in Fibonacci points (≤ 8; larger stories are split)
- [ ] MoSCoW priority set by the PO (Mahendra Umath)
- [ ] Dependencies known (upstream stories done or in the same sprint, before it)
- [ ] Test data available (synthetic generator or crafted fixture identified)
- [ ] Owner assigned
